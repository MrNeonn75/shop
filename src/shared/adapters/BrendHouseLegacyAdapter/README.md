# BrendHouseLegacyAdapter

Bu qovluq gələcəkdə mövcud **brendhouse.az** onlayn mağaza mühərriki və API-si ilə inteqrasiya üçün nəzərdə tutulmuş yerdir.

### Qeydlər:
- Tələbə əsasən, son nöqtələr (endpoints) təxmin edilmir və ixtira olunmur.
- Hər hansı konfiqurasiya və ya açar təmin edilmədiyi təqdirdə sistem aşkar şəkildə **"İnteqrasiya konfiqurasiya edilməyib" (Integration not configured)** xətasını təqdim edir.
- Gələcəkdə API sənədləri təqdim edildikdə, bu qovluq daxilində `LegacyProductAdapter` və `LegacyOrderAdapter` reallaşdırılacaq.
